# Префабы

[English version](prefabs.md)

Префаб - объект, собранный один раз и поставленный много раз: дверь, враг,
лампа со своим светом. Каждая копия в сцене (экземпляр) остаётся связана с
префабом: правка префаба доходит до всех копий, а то, что изменено в
одной копии, остаётся только у неё. Как это устроено внутри - в
[архитектуре префабов](../architecture/prefabs.ru.md).

## 1. Сделать префаб

- В "Файлах": Создать ресурс > Префаб, имя, Создать. Получится файл
  `.yprefab` с пустым `Node3D`.
- Или из готовой ветки сцены: правый щелчок по узлу в дереве > "Сохранить
  ветку как префаб...", либо перетащите узел из дерева на папку в
  "Файлах". Ветка записывается в префаб, а на её месте в сцене встаёт его
  экземпляр; ссылки других узлов на узлы ветки ведут теперь в экземпляр.
  Ctrl+Z возвращает ветку, файл префаба остаётся.

Модель (glTF) - тоже префаб, только для чтения: её узлы берутся из файла.

## 2. Поставить в сцену

Перетащите префаб или модель из "Файлов" в окно вида, на узел дерева или на
пустое место под деревом - как модель в [импорте модели](import-model.ru.md).
Узлы экземпляра в дереве своего цвета, у корня - значок префаба. Сцену
так поставить нельзя: уровень в уровень не кладётся.

Положение, поворот, масштаб и имя корня у каждого экземпляра свои.

## 3. Править префаб

Двойной щелчок по префабу в "Файлах" (или "Открыть префаб" в инспекторе
экземпляра) открывает его в окне сцены, как сцену. У префаба обычно нет
своего неба и солнца, поэтому в окне сцены он освещён светом
предпросмотра - солнцем и небом новой сцены; в файл этот свет не
попадает, кнопка с солнцем на панели окна сцены его выключает.

Сохраните префаб (Ctrl+S) - и все его экземпляры в сценах обновятся.

## 4. Изменить один экземпляр

Выберите узел экземпляра и меняйте его как обычно: свойства, компоненты,
детей. Изменённое отмечено в инспекторе цветом подписи, добавленный
компонент - цветом заголовка. Правый щелчок по свойству или заголовку
компонента:

- **Вернуть к префабу** - значение снова как в префабе;
- **Применить к префабу** - записать значение в префаб: его получат все
  экземпляры.

У корня экземпляра вверху инспектора - его префаб и кнопки "Открыть
префаб", "Вернуть всё", "Применить всё", "Распаковать". "Распаковать"
делает экземпляр обычными узлами без связи с префабом. Каждое из этих
действий отменяется одним Ctrl+Z.

Узлы префаба внутри экземпляра можно удалять и добавлять к ним новые, но
не переносить к другому родителю.

## 5. Вложенные префабы и варианты

Экземпляр одного префаба можно поставить в другой: дом с дверями. Правка
двери доходит до каждого дома. Префаб не может содержать сам себя - такой
бросок не примется.

Вариант - префаб на основе другого: правый щелчок по префабу (или модели)
в "Файлах" > "Создать вариант...". Вариант получает всё от основы и хранит
только свои отличия: синяя дверь, большая дверь.

## 6. Из кода

Редкие объекты (враг волны, предмет) создаются `instantiate`, частые
(пули, гильзы) берутся из пула `PrefabPool`, чтобы не разворачивать префаб
на каждом выстреле.

Добавьте узлу `PrefabPool` в инспекторе, выберите в нём префаб пули и
размер, а оружию дайте скрипт:

```cpp
#pragma once

#include <yqlora/scene/Prefab.hpp>
#include <yqlora/scene/PrefabPool.hpp>
#include <yqlora/scripting/Script.hpp>

class Gun : public yqlora::Script {
public:
    YQLORA_SCRIPT(Gun)

    yqlora::Ref<yqlora::Prefab> crate;
    yqlora::ComponentRef<yqlora::PrefabPool> bullets;

    YQLORA_FIELDS(field("crate", &Gun::crate), field("bullets", &Gun::bullets))

    void dropCrate();
    void fire();
};
```

```cpp
#include "Gun.hpp"

#include <yqlora/scene/Node3D.hpp>
#include <yqlora/scene/Scene.hpp>
#include <yqlora/scripting/ModuleScripts.hpp>

YQLORA_REGISTER_SCRIPT(Gun).requiresNode<yqlora::Node3D>();

void Gun::dropCrate()
{
    // Новый экземпляр ребёнком корня сцены; в игре - со следующего кадра.
    if (auto* box = static_cast<yqlora::Node3D*>(scene().instantiate(crate, *scene().root()))) {
        box->setWorldPosition(static_cast<yqlora::Node3D&>(node()).worldPosition());
    }
}

void Gun::fire()
{
    yqlora::PrefabPool* pool = scene().find(bullets);
    auto* bullet = pool ? static_cast<yqlora::Node3D*>(pool->acquire(*scene().root())) : nullptr;
    if (!bullet) {
        return;
    }
    bullet->setWorldPosition(static_cast<yqlora::Node3D&>(node()).worldPosition());
    // Через две секунды пуля возвращается в пул со значениями префаба.
    const yqlora::NodeId id = bullet->id();
    timers().after(2.0f, [this, id] {
        yqlora::PrefabPool* owner = scene().find(bullets);
        if (yqlora::Node* used = scene().find(id); owner && used) {
            owner->release(*used);
        }
    });
}
```

Поля `crate` и `bullets` заполняются в инспекторе: префаб - из "Файлов",
пул - перетаскиванием узла с `PrefabPool` из дерева. Возвращённая пуля
получает значения префаба; то, что скрипт пули держит не в своих полях,
он сбрасывает сам в `onEnable` или `onDisable`.

## Если что-то не так

- **Префаб в окне сцены тёмный**: включите свет предпросмотра (кнопка с
  солнцем на панели окна сцены) или добавьте префабу свой свет.
- **"Применить" недоступно**: префаб экземпляра - модель, она только
  читается. Сделайте вариант модели - он `.yprefab`, в него применять можно.
- **В инспекторе "Неиспользуемые переопределения"**: изменения экземпляра,
  чьей цели в префабе больше нет (узел удалили из префаба). Они хранятся,
  пока цель может вернуться; "Убрать неиспользуемые" удаляет их.
- **Префаб удалили, а экземпляры остались**: они остаются, какими были,
  и сохраняются; при следующем открытии сцены на их месте узлы-замены,
  которые хранят всё до возвращения файла (лог говорит, какой префаб не
  найден).
- **Префаб не бросается**: это сцена, или открыт префаб, который бросаемый
  уже содержит (был бы цикл).
