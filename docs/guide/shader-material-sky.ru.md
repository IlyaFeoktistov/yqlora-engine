# Свой шейдер, материал и небо

[English version](shader-material-sky.md)

Материал говорит, как выглядит поверхность: какой шейдер её рисует и с
какими значениями и текстурами. Шейдер - файл GLSL проекта. Небо - тоже
материал, с шейдером неба. Всё это файлы проекта: их создают в "Файлах" и
хранят в git вместе с `.meta`.

## 1. Материал

В "Файлах": Создать ресурс > Материал, имя, Создать. Новый материал
рисуется встроенным шейдером `Standard` и белый.

Щёлкните по нему: инспектор показывает сферу-превью, шейдер, состояние
рендера (смешивание, отсечение граней) и поля шейдера: базовый цвет,
металличность, шероховатость, свечение и карты. Изменение сразу видно на
всех объектах с этим материалом и пишется в файл, когда ползунок отпущен.
Правки материала в историю правок сцены не попадают.

Как дать материал объекту:

- перетащить материал в окно вида на объект: он ляжет в слот той части,
  что под курсором;
- или выбрать его в слоте `MeshRenderer` в инспекторе. У меша слот на
  каждый подмеш; пустой слот рисуется материалом по умолчанию.

Назначение материала - правка сцены: Ctrl+Z его отменяет.

Модель приносит свои материалы и текстуры: они лежат под моделью в
"Файлах", и модель, брошенная в сцену, получает их в слоты. Они из файла
и только читаются; кнопка "Сделать копию" в инспекторе даёт `.ymat` рядом
с моделью, который уже можно менять.

## 2. Шейдер

Создать ресурс > Шейдер делает освещённый шейдер из шаблона: цвет,
текстура, металличность и шероховатость. Двойной щелчок в "Файлах" (или
кнопка Открыть в его инспекторе) открывает его в программе, которой система
открывает `.yshader`.

```glsl
#version 450
#include <yqlora/standard.glsl>

layout(set = 2, binding = 0, std140) uniform Material {
    vec4 baseColor;  //@ color default(1, 1, 1, 1)
    float roughness; //@ range(0, 1) default(0.5)
} material;

layout(set = 2, binding = 1) uniform sampler2D baseColorMap; //@ default(white)

#ifdef YQLORA_VERTEX
void main()
{
    standardVertex();
}
#endif

#ifdef YQLORA_FRAGMENT
void main()
{
    vec4 color = material.baseColor * texture(baseColorMap, vUv0);
    Surface surface = defaultSurface();
    surface.baseColor = color.rgb;
    surface.alpha = color.a;
    surface.roughness = material.roughness;
    fragColor = shade(surface);
}
#endif
```

- В одном файле обе стадии: движок компилирует его с `YQLORA_VERTEX` и с
  `YQLORA_FRAGMENT`.
- Блок `Material` (набор 2, привязка 0) и текстуры набора 2 становятся
  полями каждого материала с этим шейдером. Комментарии `//@` говорят, как
  инспектор их показывает: `color`, `range(min, max)`, `default(...)`,
  `label("...")`, `hidden`.
- `shade(surface)` освещает поверхность всеми источниками сцены, их тенями,
  светом неба и его отражениями. Шейдер, который задаёт только
  `baseColor`, всё это тоже получает.

Сохраните файл и вернитесь в редактор: он компилирует изменённые шейдеры,
когда его окно получает фокус, и все материалы с шейдером обновляются.
Ошибка уходит в панель лога как `файл:строка: текст`; щелчок по ней
открывает файл на этой строке. Пока шейдер не компилируется, его материалы
рисуются пурпурным (`Error`).

Чтобы шейдер заработал, выберите его в поле Шейдер материала.

## 3. Небо

Небо сцены - поле `sky` её узла `Environment` (в новой сцене он есть).
Встроенное `Default Sky` - физическое небо атмосферы: оно следует за
солнцем.

Своё небо: Создать ресурс > Шейдер неба, затем материал с этим шейдером,
затем этот материал в поле `sky` у `Environment`. Шейдер неба задаёт одну
функцию:

```glsl
#include <yqlora/sky.glsl>

vec3 sky(vec3 direction)
{
    // яркость неба в нитах в этом направлении
}
```

Шаблон рисует цвет от горизонта к зениту, диск солнца и ореол вокруг него.
Небо ещё и освещает сцену: окружающий свет и отражения берутся из него
(`ambientSource` у `Environment`: `Sky`, `Gradient` или `Color`).

## 4. Свет

- Солнце - `DirectionalLight3D` с флажком `sun`; его поворот - направление
  света и время суток физического неба.
- `PointLight3D` и `SpotLight3D` светят вокруг себя до своей дальности.
- Единицы физические: солнце в люксах (по умолчанию 100000), лампы в
  канделах (130, лампочка 100 Вт). Экспозиция камеры (`exposure` у
  `Camera3D`, EV100) говорит, насколько яркая картинка: 15 для солнечного
  дня, меньше для комнаты или ночи.
- У каждого источника свои тени: нет, резкие или мягкие; `castShadows` и
  `receiveShadows` у `MeshRenderer` выключают их для одного объекта.
  Настройки проекта > Графика держат настройки теней всего проекта.

## Если что-то не так

- **Объект пурпурный**: его шейдер не компилируется (см. лог) или в слоте
  меша стоит материал неба.
- **Неба нет**: в сцене нет `Environment`, его поле `sky` пусто или у
  материала в нём шейдер не неба (об этом скажет лог).
- **Всё белое или чёрное**: экспозиция камеры не подходит к свету; лампа
  ночью при EV100 15 почти чёрная.
- **Материал не меняется**: он из модели; сделайте копию.
