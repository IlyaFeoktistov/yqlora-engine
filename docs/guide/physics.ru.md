# Физика

[English version](physics.md)

Предметы, которые падают, сталкиваются, отскакивают, скользят и висят друг
на друге, игрок, который поднимается по лестнице, зоны, которые замечают,
кто в них вошёл. Физика работает только в Play и в собранной игре;
редактируемая сцена стоит на месте. Как это устроено внутри - в
[архитектуре физики](../architecture/physics.ru.md).

Единицы - метры, килограммы и секунды; гравитация тянет вниз по Y с
9.81 м/с2.

## 1. Падающий ящик

1. Добавьте `Node3D` с мешем куба (перетащите встроенный куб в сцену).
2. Добавьте ему `BoxCollider`: он сразу берёт размер куба.
3. Добавьте `RigidBody`: `motion` - `Dynamic`, `mass` - 1 кг.
4. Добавьте пол: ещё один куб с масштабом (10, 0.2, 10) и только с
   `BoxCollider`. Коллайдер без тела выше - сам по себе неподвижное тело,
   поэтому стене или полу больше ничего не нужно.
5. Нажмите Play: ящик падает и ложится на пол.

Тело складывается из коллайдеров своего узла и его детей, до следующего
ребёнка со своим `RigidBody`: стол - одно тело из пяти коллайдеров-коробок
на детях. `motion` говорит, как тело движется:

- `Dynamic` - его толкают гравитация, силы и удары;
- `Kinematic` - его двигает только код или анимация, оно толкает
  динамические тела и везёт то, что на нём стоит (лифты, движущиеся
  платформы);
- `Static` - не движется никогда.

## 2. Формы коллайдеров

- `BoxCollider`, `SphereCollider`, `CapsuleCollider`, `CylinderCollider` -
  простые фигуры, самые быстрые; берите их, когда они достаточно похожи.
- `ConvexCollider` - выпуклая оболочка меша (камень, бочка): дыры и
  вмятины заполняются.
- `MeshCollider` - точные треугольники меша: для геометрии уровня, только
  у неподвижных и кинематических тел.

Окно сцены рисует коллайдеры выбранного узла, а кнопка "Показать
коллайдеры" на его панели - все. Тяните круглые ручки на сторонах фигуры,
чтобы менять размер (противоположная сторона стоит), с Alt двигаются обе
стороны, с привязкой размер идёт шагом сетки. "Подогнать под меш" в
инспекторе коллайдера снова подгоняет его под меши узла.

## 3. Трение и отскок

Файлы > Создать ресурс > Физический материал. У физического материала
есть `friction` (0 - лёд, 0.6 - по умолчанию, 1 и больше - резина) и
`restitution` (0 - без отскока, 1 - отскакивает так же высоко). Бросьте
его на поле `material` коллайдера. Коллайдер без материала берёт материал
проекта по умолчанию (Проект > Настройки проекта > Physics), там же
задаются гравитация, шаги решателя и какие слои с какими сталкиваются.

## 4. Столкновения и триггеры в коде

`RigidBody` сообщает, когда начинает чего-то касаться, продолжает и
перестаёт: `onCollisionEnter`, `onCollisionStay`, `onCollisionExit`. В
записи `Collision` - узел другого тела, коллайдеры, точки касания,
нормаль и `impulse`, сила удара:

```cpp
class Crate : public yqlora::Script {
public:
    YQLORA_SCRIPT(Crate)

    float breakImpulse = 20.0f;  // с какой силы удара ящик ломается

    YQLORA_FIELDS(field("breakImpulse", &Crate::breakImpulse).range(0.0f, 1000.0f))

    void onStart() override
    {
        auto* body = node().getComponent<yqlora::RigidBody>();
        body->onCollisionEnter
            .connect(*this, [this](const yqlora::Collision& hit) {
                if (hit.impulse > breakImpulse) {
                    scene().destroy(node());
                }
            })
            .release();
    }
};
```

Те же события можно связать в инспекторе без кода, см.
[события](../architecture/events.ru.md).

Триггер - зона, которая никого не толкает и сообщает, кто вошёл:
включите `isTrigger` у коллайдера и слушайте `onTriggerEnter` и
`onTriggerExit` этого коллайдера (контрольная точка, дверь, которая
открывается, вода). По умолчанию триггер замечает только движущиеся тела;
`detectStatic` заставляет замечать и остальные.

## 5. Толкать тела и спрашивать мир

```cpp
auto* body = node().getComponent<RigidBody>();
body->addForce({0.0f, 0.0f, -10.0f});                           // ньютоны, этот шаг
body->addForce({0.0f, 5.0f, 0.0f}, ForceMode::VelocityChange);  // прыжок, масса не важна
body->teleport({0.0f, 2.0f, 0.0f}, Quat(1.0f, 0.0f, 0.0f, 0.0f)); // перенести сразу

// Что в 10 м перед камерой? Слои - маска, триггеры пропускаются.
if (const auto hit = physics().raycast(origin, forward, 10.0f)) {
    debugDraw().point(hit->point, 0.2f);
}
```

`ForceMode` говорит, как читать вектор: `Force` (ньютоны на следующий
шаг), `Acceleration` (то же без массы), `Impulse` и `VelocityChange`
(сразу). Запросы ещё протягивают фигуры (`sphereCast`, `boxCast`,
`capsuleCast`) и находят, что внутри фигуры (`overlapSphere`,
`overlapBox`, `overlapCapsule`). Гизмо > Физика показывает лучи, касания,
скорости и спящие тела в окнах сцены и игры.

## 6. Игрок: контроллер персонажа

Тело, которое толкают силами, - дёрганый игрок. `CharacterController` (на
узле без `RigidBody`) - капсула, которая движется ровно так, как просят:
скользит вдоль стен, поднимается на ступени ниже `stepHeight`, держит ноги
на земле при спуске, останавливается у склонов круче `slopeLimit`, едет
на платформах и толкает лёгкие тела.

```cpp
void onUpdate(float delta) override
{
    auto* controller = node().getComponent<CharacterController>();
    Vec3 velocity = moveInput() * speed;   // как двигаться, решает игра
    if (!controller->isGrounded()) {
        m_fall -= 9.81f * delta;           // контроллер сам не падает
    } else {
        m_fall = 0.0f;
    }
    velocity.y = m_fall;
    controller->move(velocity, delta);
}
```

Прыжок, гравитация, бег и приседание (`resize`) - дело игры, поэтому игра
может парить, прыгать дважды или ходить по стенам.

## 7. Скрепления и цепи

Скрепление связывает своё тело с другим телом (`connectedBody`) или с
миром: `HingeJoint` - дверь или колесо, `SliderJoint` - ящик стола или
лифт, `PointJoint` и `DistanceJoint` - то, что висит, `FixedJoint` -
склеить, `ConeJoint` и `SwingTwistJoint` - плечи и звенья цепи,
`SixDofJoint` - всё остальное. У петли и слайдера есть пределы, мягкая
пружина на пределах и мотор: скрипт ставит `motorTarget`, чтобы открыть
дверь или крутить колесо. `breakForce` заставляет скрепление рваться под
нагрузкой и вызывать `onBreak`.

Окно сцены рисует скрепления выбранного узла: точку крепления, ось и
пределы. Точку крепления можно тянуть.

Правый щелчок в дереве сцены > Создать > Цепь... делает цепь из звеньев-
капсул между двумя точками; "Указать" ставит точку щелчком в окне сцены.
Создать > Цепь тел... делает `PhysicsChain`: длинное тело, которое гнётся
мышцами (`setBend`) и ползёт за счёт сцепления, - для змеи, червя или
хвоста.

## 8. Что полезно знать

- Тела шагают с фиксированным шагом проекта (Настройки проекта > Time);
  силы добавляйте в `onFixedUpdate`. `interpolation` тела сглаживает его
  движение между шагами для глаза.
- Быстрое маленькое тело (пуля) может пролететь сквозь тонкую стену:
  включите `continuousCollision`.
- Длинные цепи с тяжёлым грузом тянутся: поднимите `solverStepsOverride`
  у их скреплений.
- Слои узлов задают, что с чем сталкивается (Настройки проекта >
  Physics); два коллайдера можно попросить не замечать друг друга и из
  кода (`physics().ignoreCollision`).
