# Анимация

[English version](animation.md)

Анимация свойств узлов и компонентов во времени: ресурс анимации,
компонент, который её проигрывает, и панель редактора с ключами на шкале
времени.

Пометки состояния: см. [README](README.ru.md).

## Решения [planned]

- **Анимировать можно любое зарегистрированное свойство.** Дорожка называет
  узел и свойство узла или одного из его компонентов; что можно
  анимировать, берётся только из реестра типов, поэтому свойство, добавленное
  в тип (и поле скрипта), анимируется без лишней работы.
- **Три части, каждая сама по себе**: ресурс анимации `.yanim` (дорожки и
  ключи, без сцены), компонент `AnimationPlayer` (какая анимация, время,
  скорость), панель "Анимация" в редакторе (правка). Ресурс ничего не знает
  о проигрывателе, проигрыватель ничего не знает о панели.
- **Пути, а не ID**, внутри анимации: дорожка называет узел путём от
  корневого узла проигрывателя (`Body/Arm`), поэтому одна анимация подходит
  любой копии модели или сцены с тем же деревом.
- **Значения интерполируются по их типу**, а не наугад: числа и векторы
  линейно или по кривой, цвета в линейном RGB, повороты кватернионами (по
  короткому пути), а bool, int, перечисления, строки, ссылки на узлы и
  ресурсы только ступенькой.
- **Анимация работает в фазе update**, системой сцены `AnimationSystem` в
  `systems.update`, после `onUpdate` скриптов: скрипты запускают,
  останавливают и перематывают анимации в `onUpdate` и видят анимированные
  значения в `onLateUpdate`. Физика в фиксированном шаге видит значения
  прошлого кадра.
- **Правки анимации идут в историю правок** (отмена и повтор) и
  сохраняются по Ctrl+S вместе со сценой; несохранённая анимация помечается
  так же, как несохранённая сцена. Ключи правят часто и помногу, поэтому
  отмена нужна сразу.
- **Не в первой версии**: смешивание и плавный переход между анимациями,
  машина состояний, скелетная анимация и скиннинг, анимации из glTF,
  анимация значений внутри материала. Каждое придёт добавлением, без смены
  формата `.yanim` (см. "Позже").

## Ресурс анимации

Файл `.yanim` (JSON, `FileFormat` версии 1):

```json
{
    "length": 2.0,
    "loop": "loop",
    "tracks": [
        {
            "node": "Body/Arm",
            "component": "",
            "property": "rotationDegrees",
            "keys": [
                {"time": 0.0, "value": [0, 0, 0], "interpolation": "linear"},
                {"time": 1.0, "value": [0, 90, 0], "interpolation": "cubic",
                 "in": [-0.3, 0.0], "out": [0.3, 0.0]},
                {"time": 2.0, "value": [0, 0, 0], "interpolation": "linear"}
            ]
        },
        {
            "node": "Body",
            "component": "MeshRenderer",
            "property": "visible",
            "keys": [{"time": 1.5, "value": false}]
        }
    ],
    "events": [{"time": 1.0, "node": "", "component": "Footsteps", "method": "step"}],
    "version": 1
}
```

- `length` в секундах; `loop`: `none` (останавливается в конце и оставляет
  последние значения), `loop`, `pingPong`.
- Дорожка: `node` (путь от корня проигрывателя, пустой для самого корня),
  `component` (имя типа, пустое для свойства узла; первый компонент этого
  типа, `#n` для другого: `Light3D#1`), `property` (зарегистрированное
  имя), `keys`, отсортированные по времени.
- Ключ: `time`, `value` (тот же JSON, что у свойства в файле сцены),
  `interpolation` отрезка после него: `constant`, `linear`, `cubic` (`in` и
  `out` - ручки касательных, смещения по времени и значению, для чисел; у
  векторов и цветов одна пара ручек на ключ для всего значения, то есть
  кривая задаёт плавность).
- События вызывают зарегистрированный метод без аргументов у компонента в
  заданное время; событие вызывается один раз за проход через его время,
  даже если кадр его перескочил.
- Свойство, переименованное через `formerly`, находится по старому имени, а
  пишется новое, как в файлах сцен. Дорожка, чей узел, компонент или
  свойство не найдены, пропускается с одним сообщением в лог и остаётся в
  файле без изменений.
- Тип значений дорожки сверяется со свойством при загрузке: ключ другого
  типа - ошибка дорожки, он не преобразуется.

## Проигрывание

```cpp
auto& player = node().component<AnimationPlayer>();
player.play(walk);              // ссылка на ресурс
player.setSpeed(1.5f);
player.seek(0.5f);
if (!player.isPlaying()) { ... }
player.stop();                  // в начало, значения остаются как есть
```

- Свойства `AnimationPlayer`: `animations` (список ссылок на `.yanim`),
  `autoplay` (одна из них, запускается в `onStart`), `speed` (отрицательная
  играет назад), `root` (ссылка на узел, пустая - владелец). Методы
  зарегистрированы, поэтому их получают скрипты на всех языках и палитра
  визуальных скриптов.
- `onFinished` - событие проигрывателя для скриптов (только у `none`).
- Пока ни одна анимация не играет, проигрыватель ничего не пишет: свойства
  хранят значения, заданные скриптами или сценой.
- Пути к узлам и свойствам разрешаются при запуске анимации и заново после
  изменения дерева (`Scene` сообщает проигрывателю через отложенные
  изменения дерева), а не каждый кадр.
- Перезагрузка ресурса (новая ревизия) заново разрешает дорожки и сохраняет
  время.

## Редактор: панель "Анимация"

Панель внизу, вкладка рядом с Файлами и Логом.

```
[AnimationPlayer: Hero v] [walk v] [|<] [>] [>|]  0.50 / 2.00 s  [Loop v] [* Rec]
-----------------------------------------------------------------------------
 Дорожки                    | 0.0      0.5      1.0      1.5      2.0
 Body/Arm  rotationDegrees  |  <>                <>                <>
 Body  MeshRenderer.visible |                            <>
 События                    |                  |
```

- Панель правит анимации `AnimationPlayer`, выбранного в дереве (или
  проигрывателя над выбранным узлом); второй список выбирает анимацию,
  "Новая анимация" создаёт `.yanim` через окно создания.
- **Шкала времени**: линейка с масштабом (колесо) и прокруткой, текущее
  время - линия, которую тянут мышью, привязка времени к шагам (0.1 с по
  умолчанию, Shift выключает), длина тянется за конец линейки.
- **Ключи**: ромбы на строках дорожек; выбор щелчком, Ctrl+щелчком и рамкой;
  перетаскивание по времени; Delete; копирование и вставка в текущее время;
  интерполяция выбранных ключей в контекстном меню.
- **Добавление ключей**: кнопка ключа рядом с каждым свойством в инспекторе
  ("Добавить ключ в текущее время", кнопка закрашена, когда у свойства есть
  ключ в это время); режим записи (Rec): каждое изменение свойства в
  инспекторе или манипулятором добавляет или меняет ключ его дорожки,
  создавая дорожку, если её нет.
- **Предпросмотр**: перетаскивание времени или кнопка проигрывания применяют
  анимацию к редактируемой сцене. Значения, которые меняет анимация,
  запоминаются до первого предпросмотра и возвращаются, когда предпросмотр
  останавливается, панель закрывается, сцена сохраняется или сравнивается
  для "не сохранено", так что предпросмотр никогда не делает сцену
  изменённой и не попадает в файл.
- **Кривые** дорожки (значение во времени с ручками cubic) - второй вид
  панели, переключается кнопкой; в первой версии они открываются для
  дорожек float и компонент векторов.
- Логика (выбор ключей, команды, привязка, предпросмотр с возвратом) живёт
  в `editor/src` без ImGui; панель в `editor/ui` только рисует её.

## Фазы (коммит на фазу)

### A.1 Ресурс и интерполяция

- `AnimationData` (дорожки, ключи, события), загрузчик и запись `.yanim`,
  вид ресурса.
- Интерполяция по типу `PropertyValue`: constant, linear, cubic, цвета в
  линейном RGB, повороты через кватернионы.
- **Тесты**: линейные и cubic значения между ключами; ступенька для bool,
  перечислений и ссылок; поворот от 350 до 10 градусов идёт через 0, а не
  через 180; ключ неверного типа - ошибка дорожки; файл проходит через JSON
  и обратно, сохраняя неизвестные дорожки.

### A.2 Проигрывание

- `AnimationPlayer`, `AnimationSystem` в `systems.update`, разрешение
  путей, `none`, `loop`, `pingPong`, отрицательная скорость, события,
  `onFinished`.
- **Тесты**: после `advance` у свойства значение этого времени; скрипт видит
  анимированные значения в `onLateUpdate`; переименованный узел пропускает
  свою дорожку с одним сообщением; событие вызывается один раз, когда кадр
  его перескакивает; `stop` оставляет значения; новая ревизия сохраняет
  время.

### A.3 Панель "Анимация"

- Панель, шкала времени, ключи и их команды в истории, кнопка ключа в
  инспекторе, Rec, предпросмотр с возвратом.
- **Тесты** (логика редактора): добавление, перемещение и удаление ключей
  отменяются; Rec добавляет ключ при изменении свойства; после
  предпросмотра сцена не изменена; привязка времени.

### A.4 Кривые и документы

- Вид кривых; документы: этот файл (пометки [done]), сцена (компонент),
  проект (формат), редактор (панель), руководство "Анимация двери", README.
