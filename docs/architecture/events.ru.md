# События

[English version](events.md)

Событие - то, о чём компонент сообщает другим: таймер истёк, кнопку
нажали, тело вошло в триггер. Код на него подписывается, а сцена может
связать его в инспекторе без кода: "когда эту кнопку нажали, вызвать `open`
у той двери". На нём построены таймеры, интерфейс игрока (шаг 8) и физика
(шаг 6).

Пометки статуса: см. [README](README.ru.md).

## Решения [planned]

Устройство - устоявшееся для событий компонентов: подписчики из кода и
постоянные подписчики, сохранённые со сценой и вызываемые через отражение.

- **`Event<Args...>`** - член компонента, регистрируется как свойство
  (`.event("onTimeout", &Timer::onTimeout)`) с именами аргументов; типы
  аргументов - типы свойств, поэтому скрипты Luau и визуальные скрипты
  получают события без лишней работы.
- **Подписчики из кода**: `connect(owner, callback)` возвращает
  `Connection`. Владелец - компонент: когда он уходит из сцены, его
  подписки снимаются, поэтому обработчик уничтоженного компонента не
  вызывается никогда. `Connection` отписывается по `disconnect()` или при
  уничтожении, если его не отпустили `release()` жить столько же, сколько
  владелец.
- **Постоянные подписчики** - значение свойства события: список целей
  (`NodeRef`, компонент по его `ComponentId`, имя метода), задаётся в
  инспекторе и сохраняется со сценой. Когда событие срабатывает, метод
  вызывается через реестр (`Method::call`) с аргументами события; метод,
  чьи параметры не подходят, отмечается в логе один раз и пропускается.
  Цель внутри префаба переводится, как любой `NodeRef` (см.
  [префабы](prefabs.ru.md)).
- **Срабатывание** (`emit(args...)`): сначала подписчики из кода, в порядке
  подписки, затем постоянные по порядку списка. Подписчик, добавленный во
  время срабатывания, впервые вызывается следующим срабатыванием,
  удалённый во время срабатывания больше не вызывается. Исключение в
  подписчике ловится и пишется в лог с событием и подписчиком, остальные
  всё равно вызываются, как защищены вызовы жизненного цикла.
- **Только в той сцене, где задано**: постоянный подписчик вызывается в
  копии Play и в игре, но не в редактируемой сцене редактора.
- **Без общей шины сообщений**: событие принадлежит компоненту, поэтому
  кто сообщает и кто слушает, видно в коде и в инспекторе.

## Редактор

- Свойство события показывает постоянных подписчиков списком: поле узла
  (на него бросают узел из дерева), затем список компонентов этого узла,
  затем их методы с подходящими событию параметрами, с именами
  параметров. Один шаг отмены на изменение.

## Фазы (коммит на фазу)

### EV.1 События из кода

- `Event<Args...>`, `Connection`, подписки с владельцем, правила порядка и
  повторного входа, защищённые вызовы; `.event(...)` в реестре.
- Тесты: обработчик уничтоженного владельца не вызывается; подписка и
  отписка во время срабатывания; исключение в одном подписчике не
  останавливает следующего; уничтоженный `Connection` отписывается.

### EV.2 Постоянные подписчики

- Значение свойства события (`EventValue`: список целей), его
  сериализация, вызов через `Method::call`, неподходящая цель отмечается
  один раз; список в инспекторе.
- Тесты: подписчик, заданный на одном узле, вызывает метод другого после
  сохранения и загрузки; удалённая цель пропускается без потока ошибок;
  подписчики не работают в редактируемой сцене; один шаг отмены на
  изменение.
