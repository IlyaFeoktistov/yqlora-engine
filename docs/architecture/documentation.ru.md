# Документация и выпуск

[English version](documentation.md)

Шаг 10 MVP: то, что нужно человеку, чтобы сделать игру, не читая исходники
движка, и выпуск 0.0.2, которым закрывается MVP.

Пометки статуса: см. [README](README.ru.md).

## Решения [planned, step 10]

Устройство - устоявшееся для открытого движка: справочник API,
собранный из заголовков и проверяемый CI, сайт, собранный из папки `docs/`
на двух языках, снимки экрана, сделанные скриптом, учебник, чей проект
собирает CI, выпуск, собранный CI, с журналом изменений.

- **Справочник API** из публичных заголовков (`engine/include/`) через
  Doxygen, по-английски и по-русски: описание каждого публичного класса,
  функции и свойства держит оба языка рядом (многоязычные комментарии
  Doxygen, `\~english` и `\~russian`), и Doxygen собирает по справочнику на
  язык. Обе части стоят вместе, поэтому при изменении метода видно, что
  обновить надо обе. Публичный символ без описания или без одного из его
  языков роняет CI (`WARN_IF_UNDOCUMENTED` как ошибка и проверка двух
  частей). Внутренние заголовки (`internal/`) и исходники в справочник не
  входят и оставляют свои комментарии как есть.
- **Сайт**: документы `docs/` (руководства, архитектура) и справочник,
  собранные MkDocs Material (MIT) с английской и русской версией рядом,
  публикуются на GitHub Pages через CI. Ссылки и якоря каждого документа
  проверяет CI (`tools/check_links.py`), как уже проверяются переводы.
- **Руководство по редактору**: каждая панель, меню, окно и клавиша, по
  странице, со снимками экрана. Снимки делает скрипт: редактор открывает
  демонстрационный проект и сохраняет картинки своих окон
  (`yqlora --screenshots`, через `rhi::Device::readPixels`), поэтому они
  остаются верными после каждого изменения.
- **Учебник "Первая игра"**: от пустого проекта до собранной игры:
  персонаж, который ходит и прыгает, предметы для сбора, счёт на HUD,
  главное меню и меню паузы, звуки и музыка, сборка. Его проект лежит в
  `examples/first-game/`, CI собирает его и запускает без окна, поэтому
  учебник не ломается молча.
- **Выпуск 0.0.2**: версия в `CMakeLists.txt`, `CHANGELOG.md` (форма Keep a
  Changelog, по-английски, рядом русская версия), процесс CI, который
  собирает редактор с проигрывателями для Windows и Linux, гоняет тесты и
  прикладывает архивы к выпуску GitHub по тегу `v0.0.2`.

## Фазы (коммит на фазу)

### D.1 Справочник API

- Настройка Doxygen (`make docs`) для обоих языков, описания каждого
  публичного символа по-английски и по-русски, проверка в CI.
- Тесты: CI падает на публичной функции без описания и на функции только
  с одним языком; оба справочника собираются без предупреждений.

### D.2 Сайт и проверка ссылок

- MkDocs Material с обоими языками, навигация, `check_links.py` в CI,
  публикация на GitHub Pages.
- Тесты: битый якорь роняет CI; у каждой английской страницы есть русская
  пара (как `check_translations.py`).

### D.3 Руководство по редактору

- Страницы руководства, скрипт снимков и его демонстрационный проект.
- Тесты: прогон снимков делает каждую картинку, на которую ссылается
  руководство.

### D.4 Учебник

- `examples/first-game/`, страницы учебника, задача CI, которая собирает
  проект и запускает его без окна на несколько секунд.
- Тесты: задача собирает папку игры, и проигрыватель выходит с кодом 0.

### D.5 Выпуск 0.0.2

- Версия, `CHANGELOG.md`, процесс выпуска, тег, README.
- Тесты: процесс выпуска на пробном теге делает оба архива, и редактор
  каждого архива запускается и открывает проект учебника.
