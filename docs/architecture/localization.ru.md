# Локализация

[English version](localization.md)

Тексты редактора, а позже и игр, на нескольких языках.

Пометки статуса: см. [README](README.ru.md).

## Файлы и ключи [done]

- По файлу на язык: `assets/locales/<код>.json` (`en.json`, `ru.json`).
  Вложенные объекты превращаются в ключи через точку:
  `{"editor": {"menu": {"save": "Save scene"}}}` даёт `editor.menu.save`.
- `language.name` - название языка на нём самом ("Русский"); меню языков
  строится по найденным файлам, больше нигде список языков не записан.
- Группы ключей:

| Ключи | Что |
|---|---|
| `editor.*` | тексты редактора: меню, окна, панели, диалоги |
| `projects.*` | менеджер проектов |
| `type.<Type>.description` | подсказка зарегистрированного типа |
| `property.<name>` | подпись свойства (и поля записи) в инспекторе и окне настроек, `Property::labelKey` |
| `enum.<Value>` | подпись значения перечисления в списке, `enumValueLabelKey`; одно имя значит одно и то же во всех перечислениях |
| `group.<name>` | заголовок группы свойств (`group("group.ambientLight")`) |
| `editor.settings.<Section>` | название раздела в окне настроек |

- Имена узлов, типов и свойств в файлах сцен не переводятся: это
  идентификаторы, всегда на английском.

## Поиск перевода [done]

- `tr(key)` даёт текст на текущем языке. Ключ, которого в нём нет, берётся из
  английского; ключ, которого нет нигде, возвращается как есть, чтобы
  забытый перевод было видно, а не получить пустую строку.
- Свойство без ключа `property.<name>` показывается своим именем с заглавной
  буквы, поэтому тип игры работает и до перевода.
- Язык выбирает пользователь (Вид -> Язык), сначала - первый язык системы, для
  которого есть файл; выбор хранится в настройках пользователя, а не в
  проекте.
- `tr` - одна из двух служб движка с общей точкой доступа (вторая - лог):
  приложение ставит действующую `Localization`.

## Правила [done]

- У каждого зарегистрированного типа движка есть описание на каждом языке,
  а у каждого его видимого свойства (и полей записей) и каждого значения
  перечисления - подпись на каждом языке; это проверяют тесты, поэтому
  новый тип, свойство или значение без ключа в `en.json` и `ru.json` валит
  тесты. Голое имя переменной в инспектор не попадает.
- Скрипт называет свои поля через `displayName("ключ или текст")`, шейдер -
  поля материала через `//@ label("ключ или текст")`: ключ переводится,
  текст показывается как есть.
- Тексты добавляются во все файлы языков в одной правке.
